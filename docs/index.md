# **Integración Numérica: Cuadratura Gaussiana

## **Problema

El objetivo de esta implementación es calcular numéricamente una integral definida utilizando el método de cuadratura Gaussiana para integración utilizando polinomios de Legendre. Asimismo, se ocupa determinar el valor de subdivisiones N para el cual se llega a un valor exacto.  

## **Integral a resolver

Se busca encontrar el valor numérico de la siguiente integral:

$$
\int_{1}^{3} (x^6 - x^2 \sin(2x))  dx
$$
